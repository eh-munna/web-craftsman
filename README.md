## Topics Covered

1. Create a Redux store with `configureStore`
2. Provide the Redux store to the React application components

- Pass the Redux `store` as `<Provider store={store}>`

3. Create a Redux "slice" reducer with `createSlice`
4. Use the React-Redux `useSelector/useDispatch` hooks in React components
   - Read data from the store with the `useSelector` hook
   - Get the dispatch function with the `useDispatch` hook, and dispatch actions as needed
5. Set up the TypeScript related type Inferring

## **How to Use This Branch**

To explore the **Basic Redux** module, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/eh-munna/web-craftsman
   ```

2. **Navigate to the repository folder:**

   ```bash
   cd web-craftsman
   ```

3. **Switch to this branch:**

   ```bash
   git checkout basic-redux
   ```

4. **Install dependencies:**

   ```bash
   npm install
   ```

5. **Run the app:**

   ```bash
   npm run dev
   ```
